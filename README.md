# Disciplina de Inteligência Artificial

Este repositório acadêmico destina-se ao armazenamento, versionamento e documentação das atividades, exercícios e projetos desenvolvidos ao longo da disciplina de **Inteligência Artificial**.

---

## Descrição do Repositório

O repositório reúne os *notebooks* desenvolvidos, contemplando a implementação de algoritmos, análises de dados e rotinas práticas na linguagem Python, conforme as diretrizes pedagógicas da disciplina. As atividades são desenvolvidas e documentadas utilizando plataformas na nuvem como Google Colab e Kaggle.

---

## Estrutura de Arquivos

| Arquivo / Diretório | Descrição das Atividades |
| :--- | :--- |
| `Atividade_dataset_Iris_com_SVM .ipynb` | Notebook de avaliação do dataset Iris aplicando o algoritmo Support Vector Machines (SVM). |
| `Atividades_de_Data_Science_NumPy...` | Notebook com exercícios práticos de Data Science utilizando as bibliotecas NumPy, SciPy e Pandas (incluindo manipulação de DataFrames, interpolação, agrupamentos e estatísticas). |
| `Exercícios_Python...` | Notebook contendo os exercícios práticos iniciais desenvolvidos em Python. |
| `README.md` | Documentação oficial de apresentação e estrutura do repositório. |
| `SVM para Regressão: Previsão de Preços...` | Notebook estruturado para a resolução de problemas de regressão utilizando SVM na previsão de preços de imóveis. |
| `Summit_kaggle` (e variações `.ipynb`) | Arquivos destinados estritamente às atualizações e submissões das atividades no Kaggle, funcionando como registro de progresso e não como projetos independentes. |

*Nota: Este repositório será atualizado continuamente com a inclusão dos novos notebooks desenvolvidos ao decorrer do período letivo.*
